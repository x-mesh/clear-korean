# 한국어 문체 benchmark

Clear Korean의 지침을 바꿀 때 같은 26개 과제로 응답을 생성하고, 절대 점수와 회귀 여부를 비교한다. 기준 답안, 지침 없는 모델, 현재 Clear Korean의 세 기준점을 함께 사용한다.

## 기준점의 의미

- `reference`: 사람이 작성한 기준 답안이다. 채점기가 좋은 답변에 충분히 높은 점수를 주는지 확인하는 상한 기준이다. 유일한 정답이나 모델이 그대로 모방해야 할 문장은 아니다.
- `unguided`: Clear Korean 지침이 없는 같은 모델의 응답이다. 지침이 실제로 주는 효과를 확인한다.
- `candidate`: 평가할 Clear Korean preset을 적용한 응답이다. 현재 릴리스의 snapshot과 비교해 개선과 회귀를 판단한다.

세 기준점은 서로 다른 질문에 답한다. `reference`보다 점수가 낮다는 사실만으로 실패로 판정하지 않는다. 현재 후보가 `unguided`보다 나은지, 이전 `candidate`보다 나빠진 항목이 없는지 함께 본다.

## 평가 corpus

[`tests/benchmark/v1/cases.jsonl`](../tests/benchmark/v1/cases.jsonl)에 개발자용과 일반 사용자용, 평서형과 존댓말 사례 26개가 있다. 오류 보고, 코드 리뷰, 보안 공지, 고객 안내, 업무 메일, 회의 요약, 절차, 제품 문구, 연구·의료·금융 정보 등 26개 문체를 한 사례씩 다룬다.

각 사례에는 다음 정보가 있다.

- 사용자 요청과 사람이 쓴 기준 답안
- 장르에 맞는 사례별 평가 기준
- 반드시 보존할 사실을 검사하는 정규식
- 답변이 새로 만들어서는 안 되는 사실이나 추론

기준 답안은 필요한 정보량, 사실 범위와 자연스러운 표현의 기준이다. 더 좋은 표현이나 같은 뜻의 다른 답변도 만점을 받을 수 있다.

## 점수

각 응답은 100점 만점으로 계산한다.

- 모델 판정 80%: 자연스러움, 명확성, 문체 적합성, 간결성, 사실 보존을 각각 1~5점으로 평가한다.
- 규칙 검사 20%: 필수 사실, 금지 추론, 실제 답변 존재 여부를 검사한다.
- 치명적 실패: 답변 누락, 사실 조작, 사용할 수 없는 형식 위반, 심각한 말투 위반이 판정되면 종합 점수는 최대 50점이다.

모델 판정에는 변동이 있으므로 기본 실행은 응답을 다섯 번 생성하고 각 응답을 다섯 번 판정한다. 종합 점수 하나만 보지 않고 다섯 항목, 장르별 점수, 치명적 실패와 개별 응답을 함께 확인한다.

## v1 기준 결과

2026-08-20에 GPT-5.6 Sol, custom provider, xhigh 조건으로 각 사례를 5회 생성하고 응답마다 5회 판정했다.

| 조건 | 종합 | 자연스러움 | 명확성 | 문체 적합성 | 간결성 | 사실 보존 | 치명적 실패 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 사람 기준 답안 | 100.00 | 5.000 | 5.000 | 5.000 | 5.000 | 5.000 | 0 |
| 지침 없음 | 90.83 | 4.903 | 4.872 | 4.718 | 4.391 | 4.332 | 9 |
| Clear Korean 0.2.4 | 92.50 | 4.911 | 4.869 | 4.748 | 4.589 | 4.457 | 8 |
| 사실 범위 규칙 추가 | 96.95 | 4.914 | 4.929 | 4.865 | 4.800 | 4.785 | 0 |

사실 범위 규칙을 추가한 후보는 0.2.4보다 종합 점수가 4.45점 높았다. 간결성은 0.21점, 사실 보존은 0.33점 올랐고 치명적 실패는 8건에서 0건으로 줄었다. 지침 없음과 비교하면 종합 점수는 6.12점 높다.

금융 정보와 초보자 설명은 5회 표본에서 각각 7.54점과 5.24점 낮아 경고가 발생했다. 별도로 각 조건을 10회 생성하고 5회 판정한 결과, 금융 정보는 후보가 17.13점 높았고 초보자 설명은 0.76점 낮았다. 금융 정보 하락은 표본 변동으로 확인됐으며, 초보자 설명의 정확성과 간결성은 다음 개선에서 계속 추적한다.

### GPT-5.6 Luna 비교

같은 현재 지침과 5×5 조건에서 GPT-5.6 Luna가 생성한 응답을 GPT-5.6 Sol로 판정했다. 생성 모델과 판정 모델을 분리해 Sol 응답과 같은 판정 기준을 적용했다.

| 생성 모델 | 종합 | 자연스러움 | 명확성 | 문체 적합성 | 간결성 | 사실 보존 | 치명적 실패 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| GPT-5.6 Sol | 96.95 | 4.914 | 4.929 | 4.865 | 4.800 | 4.785 | 0 |
| GPT-5.6 Luna | 93.18 | 4.891 | 4.878 | 4.794 | 4.562 | 4.566 | 6 |

Luna는 종합 점수가 3.77점 낮았다. 130개 대응 표본의 평균 차이에 대한 95% 신뢰 구간은 -5.97점부터 -1.57점까지였다. 자연스러움 차이는 0.02점으로 작았지만 간결성은 0.24점, 사실 보존은 0.22점 낮았다. 고객 공지, 절차 안내, 장애 현황과 회의 요약에서 하락이 컸다. 초보자 설명, 금융 정보, 업무 이메일은 Luna가 더 높았다.

Luna를 판정 모델로도 사용하려 했지만 탭 구분 점수 형식을 반복해서 바꾸거나 점수 숫자를 누락해 전체 실행을 완료하지 못했다. 따라서 모델 품질 비교에는 완료된 Sol 교차 판정만 사용한다. `CODEX_ISOLATED_JUDGE_MODEL`을 지정하면 생성 모델과 판정 모델을 따로 선택할 수 있다.

## 기준점 만들기

`codex-isolated`는 지정한 provider 설정만 유지하고 전역 지침과 세션을 격리한다. 아래 세 실행은 모델, provider, reasoning effort, 반복 횟수가 같아야 한다.

```bash
python3 scripts/benchmark_korean.py \
  --condition reference \
  --output tests/results/benchmark-v1-reference \
  --repetitions 5 --judge-repetitions 5 --workers 8

python3 scripts/benchmark_korean.py \
  --condition unguided \
  --output tests/results/benchmark-v1-unguided \
  --repetitions 5 --judge-repetitions 5 --workers 8

python3 scripts/benchmark_korean.py \
  --condition candidate \
  --output tests/results/benchmark-v1-clear-korean-0.2.4 \
  --repetitions 5 --judge-repetitions 5 --workers 8
```

원본 응답과 판정은 `tests/results/`에 남지만 Git에는 넣지 않는다. 비교에 필요한 축약 snapshot만 `tests/benchmark/v1/baselines/`에 보관한다.

```bash
python3 scripts/benchmark_snapshot.py \
  tests/results/benchmark-v1-clear-korean-0.2.4/summary.json \
  tests/benchmark/v1/baselines/clear-korean-0.2.4-gpt-5.6-sol-r5.json
```

## 지침 후보 비교

먼저 `instructions/`를 수정하고 `./scripts/build.sh`로 preset을 생성한다. 이후 같은 조건으로 후보를 평가한다.

```bash
python3 scripts/benchmark_korean.py \
  --condition candidate \
  --output tests/results/candidate-next \
  --repetitions 5 --judge-repetitions 5 --workers 8 \
  --compare tests/benchmark/v1/baselines/clear-korean-0.2.4-gpt-5.6-sol-r5.json \
  --enforce
```

다음 중 하나라도 발생하면 회귀로 판정하고 종료 코드 1을 반환한다.

- 전체 종합 점수 1점 초과 하락
- 다섯 평가 항목 중 하나가 0.15점 초과 하락
- 장르 점수가 3점 넘게 하락하고, 표준오차를 반영한 95% 단측 상한도 -3점 미만
- 치명적 실패 증가

장르 점수가 3점 넘게 낮지만 표본 변동 범위를 벗어나지 않으면 실패 대신 경고를 기록한다. 해당 장르를 조건마다 10회 이상 생성해 다시 확인한다.

점수가 올라도 개별 응답을 표본 검사한다. 채점 모델의 취향에 과적합하거나, 정규식만 만족하는 부자연스러운 답변이 생길 수 있기 때문이다. 지침 후보가 통과하면 새 snapshot을 만들되 이전 릴리스 snapshot도 남긴다.

## 비교 조건과 suite 변경

직접 비교하려면 corpus hash, 모델, provider, reasoning effort, 생성 반복 횟수와 판정 반복 횟수가 모두 같아야 한다. 실행기가 이 조건을 검사한다. 모델이나 평가 프롬프트를 바꾸면 세 기준점을 다시 측정한다.

사례, 기준 답안, 정규식이나 사례별 기준을 바꾸면 점수 척도도 달라질 수 있다. 이때 기존 v1 snapshot과 직접 비교하지 않고 `tests/benchmark/v2/`처럼 suite 버전을 올려 세 기준점을 새로 만든다. 오탈자처럼 점수에 영향을 주지 않는 수정이라도 corpus hash가 달라지므로 같은 절차를 따른다.

## 한계

이 benchmark는 문체 품질의 전부를 증명하지 않는다. 같은 계열의 모델이 답변을 만들고 판정하면 모델 고유의 선호가 반영될 수 있고, 26개 사례가 모든 대화 맥락을 대표하지도 않는다. 따라서 고정 점수는 회귀를 빨리 발견하는 도구로 사용하고, 새 문체와 실패 사례를 발견하면 사람이 검토한 사례를 다음 suite에 추가한다. 중요한 릴리스는 다른 모델 판정이나 사람의 블라인드 비교를 함께 수행한다.
