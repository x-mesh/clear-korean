# 한국어 문체 효과 평가

## 결론

Clear Korean은 평가한 12개 문체에서 전체 품질을 소폭 높였다. 가장 큰 개선은 간결성, 사실 보존과 문체 적합성에서 나타났다. 자연스러움은 기준군도 이미 높은 점수를 받아 차이가 거의 없었다. 명확성은 소폭 낮아져, 짧게 쓰는 과정에서 조건이나 설명이 줄어들지 계속 확인해야 한다.

## 최종 평가 결과

- 실행일: 2026-08-20
- 모델: `gpt-5.6-sol`
- provider: custom provider
- reasoning effort: `xhigh`
- 문체: 12종
- 반복: 문체마다 5회
- 비교 답변 쌍: 60쌍
- 블라인드 판정: 답변 쌍마다 3회, 총 180회
- 판정 방식: 답변의 기준군·처리군 출처를 숨기고 순서를 바꾼 뒤 다수결

| 결과 | 답변 쌍 | 비율 |
| --- | ---: | ---: |
| Clear Korean 우세 | 27 | 45.0% |
| 기준군 우세 | 20 | 33.3% |
| 동률 | 13 | 21.7% |

동률을 제외하면 Clear Korean이 47쌍 중 27쌍에서 이겼다. 승률 차이에 대한 양측 부호 검정의 `p` 값은 약 0.38이므로, 승패만으로 강한 통계적 우위를 주장할 수는 없다.

| 평가 항목 | 기준군 | Clear Korean | 차이 |
| --- | ---: | ---: | ---: |
| 자연스러움 | 4.956 | 4.961 | +0.006 |
| 명확성 | 4.944 | 4.900 | -0.044 |
| 문체 적합성 | 4.750 | 4.861 | +0.111 |
| 간결성 | 4.600 | 4.894 | +0.294 |
| 사실 보존 | 4.528 | 4.661 | +0.133 |
| 전체 평균 | 4.756 | 4.856 | +0.100 |

답변 쌍을 단위로 계산한 전체 평균 차이의 bootstrap 95% 신뢰 구간은 약 `+0.024`부터 `+0.181`까지였다. 이 값은 동일 모델 판정에 의존하므로 사람 평가의 신뢰 구간으로 해석하면 안 된다.

고객 공지에서 차이가 가장 컸다. 기준군은 주어지지 않은 점검 목적, 상투적인 사과와 서비스 개선 약속을 자주 덧붙였다. Clear Korean은 점검 시간과 영향을 먼저 알리고 제공된 사실만 남겼다. 작업 완료 보고와 절차 안내에서도 결과와 제한, 단계별 동작을 짧게 구분하는 효과가 있었다.

코드 리뷰, 초보자 설명과 업무 이메일에서는 일관된 개선을 확인하지 못했다. 기준군이 조건과 기준 시점을 더 자세히 보존하거나, 동료에게 더 자연스러운 완곡한 표현을 쓰는 경우가 있었다. Clear Korean의 간결성 압력이 이런 정보를 줄였을 가능성이 있다.

친구 메시지는 모든 비교가 사실상 동률이었다. 사용자가 반말을 직접 요청하면 기본 모델도 이미 자연스러운 짧은 메시지를 작성하므로 지침의 추가 효과가 작았다.

## 평가 중 발견하고 보완한 문제

초기 병렬 평가에서는 일부 응답이 실제 답변 대신 “작업을 완료했다”는 상태만 반환했다. 기준군에서도 같은 문제가 재현돼 지침만의 문제로 볼 수 없었고, 동일 프롬프트를 동시에 보낸 provider 응답이 섞였을 가능성이 있었다. 다음 조치를 적용한 최종 평가에서는 기준군과 처리군 모두 0건이었다.

- 모든 생성 요청에 답변에 노출되지 않는 고유 평가 ID를 추가했다.
- 재시도하기 전에 이전 출력 파일을 삭제했다.
- prompt와 preset hash가 같은 응답만 재사용한다.
- 요청한 답변과 결과물을 수행 상태로 대신하지 말라는 규칙을 명시했다.

## 평가 한계

- 생성과 판정에 같은 모델 계열을 사용했다. 모델 고유의 문체 취향이 점수에 반영될 수 있다.
- 점수는 절대적인 한국어 품질이 아니라 같은 요청에서 생성한 두 답변의 상대 비교에 가깝다.
- 60쌍은 문체별 경향을 탐색하기에는 유용하지만 강한 일반화를 하기에는 작다.
- 자연스러움은 기준군 평균이 4.956으로 이미 높아 ceiling effect가 크다. 더 약한 모델이나 긴 대화에서 효과가 달라질 수 있다.
- 실제 한국어 화자의 블라인드 평가는 아직 하지 않았다.

## 재현 방법

원시 결과는 크고 모델 응답을 포함하므로 Git에서 제외한다. 다음 명령은 `tests/results/` 아래에 생성 답변, 판정과 집계 결과를 저장한다.

```bash
python3 scripts/evaluate_styles.py \
  --output tests/results/$(date +%F)-gpt-5.6-sol \
  --repetitions 5 \
  --judge-repetitions 3 \
  --workers 6
```

특정 문체만 집중해서 실행할 수도 있다.

```bash
python3 scripts/evaluate_styles.py \
  --output tests/results/comparison-focus \
  --case comparison \
  --repetitions 20 \
  --judge-repetitions 3
```
